---
name: Currency comparison scope
description: Approval boundary between price comparisons and transactional money.
---

Currency conversion is authorized for travel-price comparisons only. Do not change existing booking tables or settlement amounts without separate approval.

**Why:** The user explicitly limited currency work to comparison and required provider amounts to be retained.

**How to apply:** Treat converted prices as indicative display/filter/sort values, never as authorization to migrate money data or change what bookings charge.
